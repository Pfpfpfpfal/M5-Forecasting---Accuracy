# Changelog

## 2026-08-19

### Добавлено

- Создан блокнот EDA `notebooks/eda_A.ipynb` для набора данных M5 Forecasting
- В блокнот EDA добавлены обзор данных, проверка на наличие пропущенных значений, динамика продаж, агрегированные данные по категориям, магазинам и штатам, анализ событий и SNAP, анализ цен и примечания по моделированию
- В `src/data_utils.py` добавлены многократно используемые утилиты для подготовки данных
- В `src/models.py` добавлен фабричный метод для создания моделей с поддержкой LightGBM и резервным вариантом на основе scikit-learn
- Добавлен обучающий CLI-скрипт `src/train.py`
- Добавлен CLI-скрипт для прогнозирования и отправки данных `src/predict.py`
- В `requirements.txt` добавлены зависимости проекта
- Оптимизирована загрузка CSV в EDA и `src/data_utils.py`: добавлены компактные типы данных, а `sales_train_evaluation.csv` в EDA читается только как заголовок
- Добавлены отдельные baseline-скрипты `src/baseline_train.py` и `src/baseline_predict.py`
- В baseline добавлены календарные, event, SNAP, price, lag и rolling-признаки, а также метрики RMSE, MAE и RMSLE
